---
title: Eyebrow
group: Type
order: 3
summary: A small mono label that annotates a heading or section in the Swiss style, with numbers and slashes.
use:
  - Label a section or heading with its number or category.
avoid:
  - text: The status or category of an item.
    instead: tag
  - text: The heading itself.
    instead: heading
props:
  - name: as
    type: ElementType
    default: '"span"'
    description: Element to render; use "p" when the label stands alone.
  - name: className
    type: string
    description: Extra classes, added after sw-type-label.
a11y:
  - An eyebrow is not a heading; keep the real heading as the next element so the outline stays meaningful.
  - It is named Eyebrow, not Label, so it is never confused with a form field label.
