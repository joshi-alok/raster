---
title: Sparkline
group: Display
order: 18
summary: A small trend that sits in a line of text, beside a Stat or in a table cell.
use:
  - Show a trend in a line of text, beside a figure or in a table cell.
avoid:
  - text: A trend people need to read values from.
    instead: line-chart
props:
  - name: data
    type: number[]
    description: The values, oldest first.
  - name: label
    type: string
    description: Required. What the values are; the image is named with it and a summary.
  - name: area
    type: boolean
    default: "false"
    description: Fills under the line.
  - name: format
    type: "(value: number) => string"
    description: Formats the values in the summary.
a11y:
  - 'A sparkline is one image, named with its label, its first and last values and its range, such as "Revenue, last 9 months, CHF millions: from 4.1 to 6.3, low 3.8, high 6.3".'
  - It has no axes or table. When the exact values matter, use LineChart.
