---
title: Popover
group: Overlay and navigation
order: 9
summary: A small panel anchored to the button that opens it, for extra detail or a few controls.
use:
  - Show extra detail, or a few controls, anchored to the button that opens them.
avoid:
  - text: A short name for a control.
    instead: tooltip
  - text: A task that needs focus held until it is done.
    instead: dialog
  - text: A list of actions.
    instead: menu
interactive: true
props:
  - name: title
    type: ReactNode
    description: Visible title that also names the popover. Without one, pass aria-label.
  - name: aria-label
    type: string
    description: Names a popover that has no visible title.
  - name: children
    type: "ReactNode | ({ close }) => ReactNode"
    description: The content.
  - name: placement
    type: string
    default: '"bottom start"'
    description: Position relative to the trigger; it flips when there is no room.
a11y:
  - "React route: the popover is modal, as React Aria recommends. Focus moves into it when it opens, the rest of the page is hidden from assistive technology while it is open, and an outside click lands on an underlay that closes it. Focus returns to the trigger on Escape or that click."
  - "Without React the popover is non-modal: the page stays exposed to assistive technology and a click outside light-dismisses it. popovertarget gives the button aria-expanded; Tab moves from the button into the popover, and Escape closes it. Focus stays on the button when it opens, so its panel has the group role, named by its title, not a dialog."
  - The native popover is placed with CSS anchor positioning (anchor-name on the button, position-anchor on the panel). Browsers without it centre the panel instead.
  - Use a Dialog instead when the content needs a decision before the page can be used again.
